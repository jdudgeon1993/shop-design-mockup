Every dropdown below reads straight from Supabase, live — add something in one section and it's immediately available to pick from in every section below it, no reload needed.

Everything below only ever shows and adds to this catalog — nothing gets mixed between catalogs.

Tiers

Entry / Middle / High End — every brand belongs to exactly one.

    Room Types

    Kitchen / Bath / Garage / Closet — the first filter a shopper picks in the DIY flow.

      Option Categories

      Finish / Door Style / Hardware — the customize-step types. The actual selectable values (like "Weathered Gray") live in Options below.

        Brands

        The actual vendor lines. Each belongs to one Tier — orders never mix brands, so this is the anchor everything downstream hangs off of.

          Cabinet Categories

          Base / Wall / Tall / Pantry — shared vocabulary across every brand's catalog. Each belongs to one Room Type.

            Options

            The actual selectable values — "Weathered Gray," "Brass Designer Pull" — with a default price add-on. Adding one here doesn't make it available to any brand yet; that's the next section.

              Brand Options

              The restrictions layer — a brand only ever offers what's checked here. Pick a brand, then check off everything it allows.

              Pick a brand above to see and toggle its allowed options.

              Cabinets

              A brand's actual cabinet styles — what a customer browses. No width or price here on purpose; those are real, orderable SKUs added below in Dimensions.

                Cabinet Dimensions

                The real, orderable width/SKU/price for a cabinet style — the dimension allow-list. A customer can only ever pick a size that's a real row here.
